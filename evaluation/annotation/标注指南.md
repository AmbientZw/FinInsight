# 人工标注指南（有效性验证 · 多标注员一致性）

## 一、任务

你要对 **18 份「行业研报结构化摘要」** 的整体质量打分。每份材料 = 一段**研报原文** + 一份由模型生成的**结构化摘要**（JSON，含「核心结论 / 关键数据 / 主要风险 / 投资建议 / 疑点 / 免责声明」）。

对照原文，判断这份摘要作为「投资参考摘要」**整体**好不好，在 **好 / 中 / 差** 三档里选一档。

## 二、三档判定标准（整体印象，不是逐字段打分）

### 好
- 结论、数据与原文**一致**，无编造、无张冠李戴；
- 每条关键结论/数据都标注了**出处页码**，且页码真实存在；
- 结构完整（五个字段齐全、有实质内容），**含免责声明**；
- 关键数据**数量级、单位、口径正确**。

### 中
- 大体正确，但有** 1–2 处**明显瑕疵：个别数值偏差（如把「2.1 万亿」写成「2.1 万」）、轻微遗漏次要信息、个别条目缺出处、或表述含糊；
- 不构成误导性结论，但不够严谨。

### 差
- 出现**多处**错误或**致命缺陷**：编造数据/结论、数值大面积失配、缺免责声明、无出处、结构损坏（字段缺失/空）、或混入与原文无关的内容。

## 三、从哪些方面看（提示，不是硬性打分维度）

| 看什么 | 具体问自己 |
|--------|-----------|
| 数值准不准 | 摘要里的数字，跟原文对不对得上？数量级/单位对不对？ |
| 有没有编造 | 摘要里的结论/数据，原文里找得到依据吗？ |
| 出处真不真 | 「（来源：第X页）」的页码，原文里真的存在吗？ |
| 全不全 | 原文的核心结论、主要风险，有没有漏掉？ |
| 结构对不对 | 五个字段都在吗？JSON 有没有坏、有没有空字段？ |
| 合不合规 | 有没有「免责声明/风险提示」？有没有「保证收益」这类越界承诺？ |

## 四、标注规则（务必遵守）

1. **独立盲评**：只看 `annotation_form.md`，不要看评分结果、不要看真实标签（材料里也没有）、**不要与其他标注员讨论**。
2. **三选一**：每份必须给一个确定档位（好/中/差）。实在拿不准，选「最接近」的那档，不要留空。
3. **一视同仁**：同一份材料只按「整体质量」判断，不要因为「字段多/写得多」就倾向给高分——注水堆砌不是质量。
4. **整体优先**：一处致命错误（编造、缺免责声明）即判「差」，不要让「其他方面还行」把它拉回「中」。

## 五、怎么交

1. 复制 `annotation_template.csv`，改名为 `annotation_<你的名字>.csv`；
2. 在「评级」列，给每一行（A01–A18）填入 `好` / `中` / `差` 之一；
3. 把填好的 CSV 发回，由我统一合并计算。

> 示例：
> ```csv
> 匿名ID,评级(好/中/差)
> A01,好
> A02,中
> A03,差
> ```

## 六、结果会怎么用（你不用管，只是让你知道标注的意义）

- **多标注员一致性**：计算 Fleiss' κ，验证「三档标准」本身能被不同人稳定执行（κ 一般要求 > 0.6）；
- **评估分 vs 人工标注一致性**：把多数标注员给出的档位，与系统自动评测总分做 Spearman 秩相关，证明「自动评分与人类判断吻合」——这是课题「有效性验证」的核心证据。
