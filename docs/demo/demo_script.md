# Demo 视频脚本（约 2 分钟）

> 目标：展示一次完整的「上传研报 → 生成摘要 → 自动评估出分」闭环，突出评估方法的判别力。

## 分镜

| 时间 | 画面 | 台词/字幕 |
|------|------|----------|
| 0:00–0:10 | 标题卡：FinInsight — 行业研报智能分析 | "这是基于腾讯 Hy3 大模型构建的金融研报智能分析系统，配套七维度自动评估方法。" |
| 0:10–0:25 | 前端首页，点击上传一份研报 PDF | "上传一份行业研报，系统调用 Hy3 生成结构化摘要。" |
| 0:25–0:45 | 摘要结果展示：核心结论/关键数据/风险/建议/疑点，每条标注出处 + 免责声明 | "摘要包含五个标准字段，每条结论标注原文页码，并自动附加投资风险提示。" |
| 0:45–0:55 | 切换到问答框，输入一个问题 | "基于研报内容，用户可以直接提问。" |
| 0:55–1:10 | 终端运行 `python run_evaluation.py` | "现在演示评测：系统对 75 个样本跑七维度 Rubric 评分。" |
| 1:10–1:25 | 展示 `eval_table.csv` 表格 + 三档总分对比 | "好/中/差三档样本的总分呈单调下降，判别力显著。" |
| 1:25–1:45 | 展示验证报告（箱线图/统计量/对抗通过率） | "Kruskal-Wallis 检验与 Cohen's d 验证判别力，对抗样本未获虚高分。" |
| 1:45–2:00 | 结尾卡：GitHub 链接 + 免责声明 | "个人活动作品，非腾讯官方发布。输出仅供参考，不构成投资建议。" |

## 录制要求

- 分辨率 ≥ 1280×720，导出为 `.mp4` 或 `.gif`
- 前后端本地启动：`uvicorn app.main:app --reload` + `npm run dev`
- 若不便录屏，可用脚本 `docs/demo/capture.sh` 自动截图拼 GIF
