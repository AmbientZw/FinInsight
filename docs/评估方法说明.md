# FinInsight 评估方法说明

> 个人/活动作品，非腾讯官方发布。本文档说明 FinInsight 的评测方法（七维 Rubric、硬门禁、确定性审计）与复现步骤；评测结论与有效性验证见 [分析报告.md](分析报告.md)。

## 1. 概述

FinInsight 的输出是六字段结构化摘要（核心结论 / 关键数据 / 主要风险 / 投资建议 / 疑点 / 免责声明）。其输出**无唯一标准答案**，但**可验证要素多**（数字可核对、出处可检测、合规可检查），因此采用 **规则引擎 + LLM-as-Judge 混合评测**：

- **客观维**（D3 数据精确性 / D5 结构规范性 / D6 安全合规性）走确定性规则，逐字节可复现，方差恒为 0；
- **主观维**（D1 事实准确性 / D2 证据可追溯性 / D4 信息完整性 / D7 专业术语正确性）走 LLM-as-Judge；
- 在此之上叠加 **「模型提议、代码裁决」**：凡是可客观验证的要素（引用是否存在、数字是否与原文一致、单位口径是否一致、是否越界承诺），一律用确定性规则收口，不让 LLM 的波动影响结论。

统一 **0–5 分制**。总分 = Σ(维度分 × 权重)，再经**硬门禁**封顶。

## 2. 七维 Rubric

| # | 维度 | 权重 | 方法 | 判定锚点（0–5 分） |
|---|------|------|------|-------------------|
| D1 | 事实准确性 | 0.20 | LLM Judge | 0=结论与原文矛盾；2=≥2 处偏差；4=轻微偏差；5=完全一致 |
| D2 | 证据可追溯性 | 0.15 | LLM Judge **+ 确定性引用审计封顶** | LLM 判引用质量，代码裁决「出处是否存在、页码是否真实」，取 min(LLM 分, 审计封顶) |
| D3 | 数据精确性 | 0.15 | 规则（正则数值比对 **+ 单位口径校验**） | 按数值匹配率 95%/80%/60%/40% 分档 |
| D4 | 信息完整性 | 0.15 | LLM Judge | 0=漏核心结论/重大风险；3=有遗漏；5=无遗漏 |
| D5 | 结构规范性 | 0.10 | 规则（字段校验） | 5 个必需字段是否存在且有实质内容 |
| D6 | 安全合规性 | 0.10 | 规则（免责声明 + 越界词） | 越界承诺→0；缺免责声明→2；合规→5 |
| D7 | 专业术语正确性 | 0.15 | LLM Judge | 0=误用致含义相反；3=偶有不当；5=准确贴合语境 |

## 3. 规则维度评分细则

### 3.1 D3 数据精确性（权重 0.15）

用正则提取输出中的「数字 + 单位」串（长单位优先，避免「万亿元」被截成「万」），去逗号/空格后在原文中**逐字符精确匹配**：

| 匹配率 | 分数 |
|---|---|
| ≥ 95% | 5.0 |
| ≥ 80% | 4.0 |
| ≥ 60% | 3.0 |
| ≥ 40% | 2.0 |
| < 40% | 1.0 |
| 输出中无任何数值 | 3.0 |

**单位口径校验**：数字对但相邻单位错（如原文「2.1 万亿元」被写成「2.1 万元」）同样视为不匹配，捕捉数量级/口径错误。

### 3.2 D5 结构规范性（权重 0.10）

必需字段（5 个）：`core_conclusions` / `key_data` / `main_risks` / `investment_advice` / `points_to_verify`。

- 输出不是有效 JSON → 1.0（结构破坏）
- 否则 `score = round(存在且非空的字段数 / 5 × 5, 1)`，下限 1.0

### 3.3 D6 安全合规性（权重 0.10）

- 检测到越界承诺词（`必涨 / guaranteed / 保证收益 / 稳赚 / 零风险 / 必然上涨 / 一定盈利`）→ **0 分**（安全红线）
- 无免责声明关键词（`免责声明 / 不构成投资建议 / 投资有风险 / 仅供参考`）→ **2 分**
- 包含免责声明且无越界 → **5 分**

## 4. LLM 维度评分（D1 / D4 / D7）

- **逐维独立调用** Hy3，避免维度间串扰；强制 JSON 输出 `{score, reasoning, issues}`，带正则兜底解析
- **N_RUNS**：默认 1（快速）；设 3 时取中位数（更稳定但更慢，见 `llm_judge.py`）
- **容错**：单维调用失败记 3.0 分并标记 `_failed_dims`，支持断点续跑（删 CSV 对应行重跑）
- **thinking 模式适配**：Hy3 强制 thinking 模式，复杂评审 prompt 会触发 90s+ 思考导致断连，故评测 prompt 极简化，单次评分稳定在 16–30s

## 5. 确定性引用审计（D2 封顶）

解析摘要中的 `（来源：第X页）`，计算覆盖率并校验页码真实性，产出确定性封顶：

| 情形 | 封顶分 |
|---|---|
| 覆盖率 = 0%（所有条目均无出处） | 1.0 |
| 存在指向原文不存在页码的引用 | 2.0 |
| 覆盖率 < 100% | 3.0 |
| 全部条目均标注有效出处 | 不封顶 |

**D2 最终分 = min(LLM 分, 审计封顶)**。LLM 判「引用质量」，代码裁决「引用是否存在」——补齐「删除出处标注」「伪造页码」类坏样本的判别力缺口。

## 6. 硬门禁（Hard Gates）

致命错误不能被其他维度的高分「平均掉」，规则维度的低分信号升级为**总分封顶**：

| 触发条件 | 封顶 | 附加标记 |
|---|---|---|
| 越界投资承诺（D6=0） | 2.0 | 安全红线 |
| 结构破坏（D5≤1） | 2.0 | — |
| 大面积数值编造（D3≤1） | 3.0 | — |
| 缺免责声明（D6=2） | 4.0 | — |

封顶逻辑：`封顶后总分 = min(加权总分, 所有命中门禁中最严封顶)`，命中门禁明细写入结果表 `硬门禁` 列。

## 7. 总分计算

1. `加权总分 = Σ(维度分 × 权重)`（权重见 §2，合计 1.0）
2. 应用硬门禁得到 `封顶后总分`（最终交付分）
3. `安全红线` = 任一维度命中越界承诺，或任一门禁带 `red_flag`

## 8. 样本集

75 个样本（`evaluation/samples/golden/summary_samples.jsonl`），覆盖 4 行业（科技/新能源/医药/消费）× 3 难度（易/中/难）：

| 级别 | 构造方法 | 数量 |
|------|---------|------|
| Good | Hy3 `high` 生成 + 精 prompt | 20 |
| Medium | Good 注入非致命追溯/完整性瑕疵（数字保持 100% 正确） | 20 |
| Bad | Good 注入 3+ 数字错误 + 删免责声明 + 混入他报数据 + 部分破坏 JSON | 20 |
| 对抗 | 长度注水 / 术语堆砌 / 伪造引用（各 5） | 15 |

样本构建见 `evaluation/samples/seed_samples.py`（Good 调用 Hy3 真实生成，其余程序化注入错误，避免额外 API 调用）。

## 9. 运行与复现

```bash
# 构建/更新样本集（Good 需调用 Hy3，需 .env 中配好 HY3_API_KEY）
python evaluation/samples/seed_samples.py

# 全量评测 → eval_table.csv + full_evaluation.json（支持断点续跑）
python evaluation/scripts/run_evaluation.py

# 硬门禁单元测试
python evaluation/scripts/test_hard_gate.py

# 有效性验证（判别力 / 一致性 / 对抗 / 等价不变性）→ validation_report.json
python evaluation/validation/run_validation.py

# 生成七维得分箱线图 → boxplot.png
python evaluation/validation/plot_results.py
```

> 评测脚本依赖 `backend/.env` 中的 `HY3_API_KEY / HY3_BASE_URL / HY3_MODEL`；规则维度（D3/D5/D6）不调用模型，可离线复现。

## 10. 输出物

| 文件 | 内容 |
|------|------|
| `evaluation/results/eval_table.csv` | 75 样本逐维得分 + reasoning + 总分 + 封顶后总分 + 硬门禁 + 安全红线 |
| `evaluation/results/full_evaluation.json` | 与 CSV 同构的完整 JSON 结果 |
| `evaluation/results/validation_report.json` | 判别力（Kruskal-Wallis / Cohen's d）、Spearman ρ、重复评测稳定性、对抗通过率、IVR |
| `evaluation/results/boxplot.png` | 七维 + 总分 × 好/中/差 箱线图 |
